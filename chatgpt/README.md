# ChatGPT 웹 프로젝트에 넣기

1. [ChatGPT용 설치 파일](https://aihubos.github.io/kira-chan/downloads/kira-chan-chatgpt-project.zip)을 내려받아 **압축을 푼다**. ZIP 자체를 프로젝트 자료로 올리지 않는다.
2. ChatGPT에서 새 프로젝트를 만들고 이름을 `키라쨩 카드뉴스`로 정한다.
3. 프로젝트 설정의 지침에 `project-instructions.txt`의 전체 내용을 붙여 넣는다.
4. `upload` 폴더의 **5개 파일**을 프로젝트 자료로 올린다: `KIRA-HANDBOOK.md`, `reference-chibi.png`, `pixel.png`, `actions.png`, `style-card.png`.
5. 프로젝트 안에서 아래 예시로 제작한다. 참조 이미지가 생성 도구에 전달되지 않으면 해당 PNG를 대화에도 첨부한다.

파일 업로드 한도·이미지 생성·웹 검색은 계정과 워크스페이스 설정에 따라 다르다. 5개를 한 번에 올릴 수 없으면 허용되는 만큼 나누어 올린다. Markdown 업로드가 지원되지 않으면 Handbook을 `.txt`로 바꾸고 지침의 파일명도 맞춘다.

```text
키라쨩 스킬로 오늘 AI 카드뉴스 10장을 만들어줘.
최신 원문을 확인하고, 기준 캐릭터를 사용해 PNG를 한 장씩 생성해줘.
원고·출처와 Threads 문구도 함께 줘.
```

```text
첨부 보고서를 비전공자 임원용 키라쨩 카드뉴스 10장으로 만들어줘.
보고서의 사실과 너의 제안을 구분해줘.
```

```text
완성된 카드뉴스를 내 GitHub Pages에 발행할 수 있게 준비해줘.
내 저장소와 공개 주소를 확인한 후 기존 뷰어를 재사용해
새 날짜의 HTML·출처·이미지 폴더를 구성해줘.
직접 게시할 수 없으면 다운로드 파일과 웹 업로드 순서를 줘.
```

프로젝트는 지침·자료를 사용하는 방식이다. GitHub 링크 하나로 프로그램 설치나 매일 자동 발행이 끝나는 것은 아니다. 직접 GitHub에 게시하려면 쓰기 가능한 연결 도구와 계정 권한이 필요하며, 없으면 생성 파일을 다운로드해 직접 업로드한다. 발행 경로는 Handbook의 ‘제작 결과 발행’을 따른다.

업데이트할 때는 새 묶음을 내려받아 지침과 위 5개 자료를 교체한다. 같은 이름으로 중복 추가하기보다 본인이 올린 이전 버전을 확인해 정리한다. 기존 제작 대화와 결과 이미지는 유지한다.

공식 안내: [ChatGPT 프로젝트의 파일·지침·이미지 생성](https://help.openai.com/en/articles/10169521-using-projects-in-chatgpt).
