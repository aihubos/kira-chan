# KIRA-chan

카드뉴스는 발행 날짜(YYYY-MM-DD)별로 보관합니다.

- `YYYY-MM-DD/index.html`: 해당 날짜 카드뉴스 페이지
- `YYYY-MM-DD/sources.md`: 해당 날짜 원고·출처
- `assets/YYYY-MM-DD/`: 날짜와 01~10 번호를 붙인 PNG 원본
- 루트 `index.html`: 최신 발행본

새 날짜 발행 시 기존 날짜 폴더를 덮어쓰지 않습니다. 날짜별 페이지의 공유 주소도 해당 날짜 주소로 지정합니다.
